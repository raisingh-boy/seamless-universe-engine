# SEAMLESS UNIVERSE — ПОЛНЫЙ СПЕК ДЛЯ РЕАЛИЗАЦИИ

## Архитектура продукта, UI, механики, данные
### Без физики — только то, что вокруг 3D-движка

============================================================
## 1. ФИЛОСОФИЯ ПРОДУКТА
============================================================

Seamless Universe — интерактивное пространство живых знаний.
Пользователь перемещается ВНУТРИ живой среды, а не управляет графом.

Связи — речные дельты, мицелий, частицы.
Концепции — тела в поле: светятся, пульсируют, дышат.
Всё движется всегда. Ничего статичного. Никаких линий между узлами.

Пользователь двигает концепцию — поле перестраивается как река вокруг камня.

============================================================
## 2. ТРИ МИРА
============================================================

### 2.1 ATLAS (Канонический архив)
- 100-130 верифицированных концепций, readonly
- 6 кластеров по доменам: body, science, philosophy, movement, cognition, hybrid
- Иерархия внутри кластера: macro у центра, meso на орбите, micro дальше
- Полная яркость, богатые потоки, идеальные формы
- Исторические связи с документацией

### 2.2 FIELD (Живое поле)
- Концепции, добавленные пользователями (обычно 40+)
- Плоский овальный диск, ноды свободно плавают
- Любой залогиненный может добавлять, редактировать, создавать связи
- Потоки любых типов
- Два sub-режима:
  --- IDEAS: обычный вид, field-концепции + фоновые atlas (25% прозрачности)
  --- PEOPLE: концепции скрыты, показаны участники сообщества как звёзды

### 2.3 ME (Личная вселенная)
- central-me в центре координат — символ пользователя
- Только: твои концепции + те, что положил в карман + те, что резонировал
- Всё вращается вокруг central-me по орбитам
- Разные скорости орбит (внутренние быстрее)
- Приватность: Public / Overlay-only / Private

### 2.4 Переходы между мирами
- Плавный lerp ~1.5 секунды
- Концепции перелетают в новые позиции
- Без рывков и мгновенных скачков

## 3. UI — ВСЕ ПАНЕЛИ
============================================================

### 3.1 Шапка
Логотип + 3 таба миров (Atlas | Field | Me).
Активный таб с золотым подчёркиванием.
Переключатель языка RU/EN.
Аватар / кнопка Sign In.

### 3.2 Фильтр-полка
Поиск (матчит nameRu + nameEn).
Домен: радио-кнопки (ВСЕ | body | science | philosophy | movement | cognition | hybrid).
Эпоха: слайдер 0-8 (0=все, 1=античность, 2=средневековье, 3=ренессанс, 4=XIX, 5=ранний XX, 6=середина XX, 7=поздний XX, 8=современность).
Слои: чекбоксы Atlas / Field / HOT (>50 резонансов) / Audio Only.
Overlay: выбор другого пользователя для наложения графа.

### 3.3 Карточка концепции (NodeCard)
Desktop: правая панель, 460px.
Mobile: нижний sheet, 32vh-80vh, swipe up/down.

Peek-режим (всегда):
- Цветная полоса домена
- Бейдж типа + уровень (MACRO/MESO/MICRO)
- Название крупно
- 1-2 строки описания
- 4 кнопки действий

Развёрнутый режим — 4 вкладки:

① СУТЬ
- Статус + прогресс-бар к следующему уровню
- Метрики: резонансы | ранг | суммарный балл
- Индикатор здоровья: Растёт / Стабильно / Угасает
- Полное описание
- До 5 соседних концепций (кликабельные)

② ИСТОРИИ
- Форма добавления (textarea 300+ символов + опциональная ссылка на другую ноду)
- Список историй с заголовком, годом, резонансами

③ КАРТА (мини-карта)
- Выбранная нода в центре
- Соседи на орбитах (до 8)
- Клик на соседа = навигация
- 2D SVG/Canvas

④ МАТЕРИАЛЫ
- Статьи/книги/видео с бейджем типа, годом, summary, кнопкой "Открыть источник"
- Аудио-записи с кнопкой "Слушать"

Панель действий (bottom bar):
[♦ РЕЗОНИРОВАТЬ] [⟷ СВЯЗАТЬ] [↗ В КАРМАН] [+ ИСТОРИЯ]

### 3.4 Модал "Добавить смысл" (AddSenseModal)
Вызов: кнопка "+" в футере.

5 шагов:
1. Текстареа с placeholder-примерами. 3 кнопки-подсказки (вставляют текст). Кнопка "ДЕКОДИРОВАТЬ"
2. Спиннер + "Анализирую семантические паттерны..." (1.2 сек)
3. Результат: иконка типа, уверенность %, очищенное название, домен-бейдж. Кнопка "ПОДТВЕРДИТЬ"
4. "Интегрирую в поле..." (1.5 сек)
5. Зелёная галочка, "Зарождено в поле!", авто-закрытие 2 сек

Логика парсинга (детерминированная, не AI):
- "связать"/"connect"/"↔" + 2 концепции → тип CONNECTION
- "история"/"story"/"заметка" + 1 концепция → тип STORY
- иначе → тип NEW CONCEPT

Автодетекция домена по хэштегам/ключевым словам:
- #science / "физика" / "исследование" → science
- #philosophy / "философ" / "разум" → philosophy
- #movement / "танец" / "движение" → movement
- #cognition / "язык" / "слово" → cognition
- #hybrid / "пересечение" → hybrid
- default → body

### 3.5 Профиль пользователя
Имя, email, доминирующий домен (бейдж).
Статистика: зарождено смыслов, написано историй, концепций в Atlas, связей создано.
Архетипы (авто):
- CONNECTOR (много связей)
- STORYTELLER (много историй)
- RESONATOR (много резонансов)
- PIONEER (есть в Atlas)
- BRIDGE (связывает 3+ доменов)
Настройки приватности: мой граф (публичный/overlay/приватный), резонансы (видимы/скрыты)

### 3.6 Повестка сообщества
Коллапсируемые карточки вопросов.
Каждая: домен-теги, текст, аватары участников, счётчик.
Развёрнуто: ответы (автор + текст + ссылка на концепцию), форма добавления ответа.
Клик на linked concept → навигация к ноде в 3D.

### 3.7 Аудио-плеер
Два состояния:
--- Мини (всегда виден когда играет): иконка + название + автор + play/pause + развернуть
--- Полный: обложка + метаданные + временная шкала с бусинами + плейлист + управление

Бусины на временной шкале = точки в timeline записи.
Цвет бусины = домен концепции.
Клик на бусину = seek к таймкоду.
Hover на бусине = tooltip с названием и caption.
"Сейчас в эфире" блок с кнопкой "ОТКРЫТЬ" → навигация к концепции.

### 3.8 Онбординг
Показывается при первом входе (localStorage).
3 слайда: Бейтсон / Ханна / Манифест.
Навигация точками, кнопка ДАЛЕЕ, язык RU/EN, "Пропустить".

### 3.9 Vibe Mode
Три режима: COLOUR / MONO / CINEMATIC

### 3.10 Лента активности
Колокольчик в футере → список уведомлений.
Автоматически обновляется.

### 3.11 Радиальное меню
Долгий тап на концепции >650ms → 4 кнопки вокруг неё:
[♦ Резонировать] [📖 История] [⟷ Связать] [↗ В карман]
Анимация expand. Закрытие: клик вне / Escape.

### 3.12 Авторизация

По умолчанию: botovroman45@gmail.com (для разработки)

## 4. ДАННЫЕ (структуры)
============================================================

### Concept
- id (уникальный), nameRu, nameEn, descriptionRu, descriptionEn
- authorRu?, authorEn?, epochRu?, epochEn?
- type: concept | practice | person | movement | event | observation | question
- level: macro | meso | micro
- domain: body | science | philosophy | movement | cognition | hybrid
- world: atlas | field | me
- status: seed | sprout | alive | rooted | atlas
- resonances (число голосов)
- connections (сколько связей)
- carries (сколько раз положили в карман)
- score (вычисляется)
- addedBy?, isPrivate?, createdAt?, lastActiveAt?
- articles?: Article[]

### Flow (связь)
- id, sourceId, targetId
- world: atlas | field
- type: conceptual | historical | practical | resonance | opposition
- labelRu?, labelEn?
- storyIds?: string[]
- strength: 0.0-1.0
- activity: число
- addedBy?, createdAt?

### Story
- id, flowId (обязательно к какой связи)
- titleRu, titleEn, textRu, textEn
- figureA?, figureB?, year?, sourceUrl?
- resonances, verified

### Article
- id, conceptId
- titleRu, titleEn, summaryRu, summaryEn
- sourceUrl?, sourceTitle?, year?
- type: research | article | book | video

### Recording (аудио)
- id, titleRu, titleEn, authorRu, authorEn
- sourceRu, sourceEn, year, duration (сек), domain
- audioUrl?
- timeline: { timeMs, conceptId, captionRu, captionEn }[]

### AgendaQuestion
- id, questionRu, questionEn
- domains: Domain[]
- contributors: { name, avatar }[]
- answers: { id, author, textRu, textEn, linkedConceptId? }[]

### CommunityUser
- id, name, avatar
- dominantDomain
- reputation, explorer, builder, connector, storyteller
- resonances: string[] (какие концепции резонируют)

## 5. БЭКЕНД (УЖЕ ЕСТЬ — ТОЛЬКО КОННЕКТ)
============================================================

### Бэкенд уже развёрнут и работает
Не нужно строить новый. Всё уже есть на сервере.

Express сервер на localhost:3001
PostgreSQL с 402 концепциями
Ollama qwen2.5:3b на порту 11434
nginx прокси: /api/ → localhost:3001

### API эндпоинты (все работают)

POST /api/chat
  Body: { message, language, context? }
  Response: { reply: string, model: "qwen2.5:3b"|"fallback", note?: "AI model loading, using fallback" }

GET /api/nodes
  Query: ?world=atlas&domain=body&level=macro
  Response: { nodes: Concept[] }

GET /api/edges
  Response: { edges: Flow[] }

POST /api/node
  Body: Concept data (nameRu, nameEn, domain, etc.)
  Response: { id, createdAt }

POST /api/edge
  Body: { sourceId, targetId, type, labelRu?, labelEn? }
  Response: { id }

POST /api/resonate
  Body: { nodeId }
  Response: { resonances: number, newStatus?: string }

POST /api/carry
  Body: { nodeId }
  Response: { ok: true }

GET /api/stories?nodeId=X
  Response: { stories: Story[] }

POST /api/story
  Body: { flowId, titleRu, titleEn, textRu, textEn, figureA?, figureB?, year? }
  Response: { id }

GET /api/recordings
GET /api/recordings/:id
  Response: Recording with timeline array

### Что нужно знать Julius:
- Все запросы идут на /api/ (nginx проксирует)
- AI запросы: POST /api/chat — при холодном старте Ollama (~15 сек) возвращается fallback-ответ
- Статика концепций лежит в БД PostgreSQL
- Для новых field-концепций: POST /api/node

## 6. МЕХАНИКИ
============================================================

### 6.1 Жизненный цикл концепции
seed (0 резонансов) → sprout (10+) → alive (50+) → rooted (100+) → atlas (вручную)

При каждом резонансе: count++ → проверка порога → upgrade статуса.
Визуальные изменения: opacity, размер, цвет подписи.

### 6.2 Decay (угасание)
Field-концепции без активности >30 дней: прозрачность уменьшается.
Минимум: едва заметна.
Любое взаимодействие обновляет lastActiveAt.

### 6.3 Score
Вычисляется из резонансов, связей, carries.

### 6.4 Сила потоков
Сила связи = 0.2 + resonanceWeight × 0.8.
При активности растёт. В покое падает.
При минимуме — почти невидим.
При максимуме — дополнительные микро-ответвления.

## 8. ТЕХНИЧЕСКИЙ СТЭК
============================================================

Frontend:
- React 18 + TypeScript
- Vite (сборщик)
- Three.js + @react-three/fiber + @react-three/drei
- Tailwind CSS (стилизация UI)
- Lucide React (иконки)

Данные:
- localStorage для: голоса, коллекция, язык, сессия, онбординг
- Статика концепций и связей — НЕ в ts-файлах, а через API (GET /api/nodes, GET /api/edges)
- Будущее: Supabase для field-данных пользователей

Производительность:
- InstancedMesh для частиц
- LOD culling
- useRef для физики (не useState)
- Canvas DPR max 2.0

Адаптивность:
- Breakpoint: 768px
- Desktop: полная шапка, правый drawer 460px
- Mobile: компактная шапка, bottom sheets, touch-события

## 10. UX МАНИФЕСТ
============================================================

Каждая техническая деталь должна служить этим ощущениям:

1. "Я внутри живой экосистемы" — не управляю графом, двигаюсь в среде
2. "Когда я двигаю идею, мир перестраивается" — scatter/reform, не резинки
3. "Всё дышит" — пульсирующие ноды, текущие частицы
4. "Связи — реки, не проволока" — потоки без линий
5. "Время имеет значение" — угасание, рост, эволюция
6. "Я оставляю след" — резонансы, carries, связи
7. "Знания живые" — рождаются, укореняются, восходят
8. "Это пространство, а не список" — 3D, физика, пространственная память
