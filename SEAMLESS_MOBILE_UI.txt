# SEAMLESS UNIVERSE — MOBILE INTERFACE DESIGN

## Эргономика для телефона, одна рука
### Что где стоит на экране

============================================================
БАЗОВЫЙ ЭКРАН — 4 ЭЛЕМЕНТА
============================================================

Весь экран = 3D сцена. Ничего не перекрывает её без нужды.

1. ВНИЗУ ЦЕНТР — ТРИ ТОЧКИ
   Три маленькие точки / иконки: ATLAS • FIELD • ME
   Активная — подсвечена. Тап — переключение мира.
   Это единственное что всегда на экране.
   Большой палец бьёт идеально.

2. ВВЕРХУ СПРАВА — КНОПКА ФИЛЬТРОВ
   Иконка фильтра (∨ или ≡).
   Тап — выезжает фильтр-шторка сверху.
   Фильтры не постоянно, а по запросу.

3. ВНИЗУ ПРАВЕЕ ЦЕНТРА — КНОПКА "+"
   Плюсик. Добавить новый смысл.
   Чуть выше / правее трёх точек, чтобы не путать.

4. ВВЕРХУ СЛЕВА — АВАТАР / ВОЙТИ
   Маленький кружок. Тап — профиль.

Четыре элемента. Всё. Остальное появляется когда нужно.

============================================================
ТРИ ТОЧКИ НАВИГАЦИИ (внизу центр)
============================================================

Три маленькие иконки, расстояние между ними ~48px.
Активная — золотая или яркая.
При тапе — мир переключается плавно, 3D перестраивается.

Большой палец ложится идеально: нижняя треть экрана.

============================================================
ФИЛЬТР-ШТОРКА
============================================================

Выезжает сверху вниз на ~40% экрана.
Прозрачный фон (видно 3D сквозь).
Содержит:
- Строку поиска
- Домен (список иконок/букв)
- Эпоха (полоска с точками)
- Чекбоксы: Atlas, Field, HOT, Audio
- Overlay (выбор пользователя)

Свайп вверх = закрыть. Тап вне шторки = закрыть.

============================================================
3D СЦЕНА
============================================================

Во весь экран.
Обычное состояние: можно вращать и зумить (один палец вращение, два — зум/пан).
При открытой карточке или модалке — сцена на заднем плане, полупрозрачная.

============================================================
КАРТОЧКА КОНЦЕПЦИИ (нижний лист)
============================================================

Появляется снизу, когда тапаешь на концепцию.

Два состояния:

СОСТОЯНИЕ 1: СВЁРНУТАЯ (peek, ~30% экрана)
- Только: цвет домена, тип+уровень, название, пара строк
- 4 маленькие иконки действий внизу листа: ♥ ⟷ ↗ + (резонировать, связать, в карман, история)
- Можно тапнуть кнопку действия прямо отсюда
- Свайп вверх = развернуть
- Свайп вниз = закрыть
- Тап вне = закрыть

СОСТОЯНИЕ 2: РАЗВЁРНУТАЯ (~80-90% экрана)
- Статус + прогресс
- Метрики
- Описание полное
- Соседние концепции (горизонтальный скролл, тап = перейти)
- 4 таба горизонтально: Суть | Истории | Материалы | Карта
- Свайп по табам влево-вправо

ТАБЫ ВНУТРИ:
- Суть: статус, метрики, здоровье, описание, соседи
- Истории: список + кнопка "добавить"
- Материалы: список статей/книг/видео с ссылками
- Карта: мини-карта соседей (круговая, тап = переход)

Закрыть: свайп вниз или тап вне.

============================================================
МОДАЛ "ДОБАВИТЬ СМЫСЛ" (+)
============================================================

Полноэкранный на телефоне.
Появляется снизу, поднимается на весь экран.
Поле ввода вверху, результат под ним.
Кнопка действия внизу — под большим пальцем.
Крестик или свайп вниз = закрыть.

============================================================
РАДИАЛЬНОЕ МЕНЮ (долгий тап)
============================================================

Держишь палец на концепции >650ms — вокруг пальца появляются 4 иконки:
- Сверху: ♥ Резонировать
- Справа: ⟷ Связать
- Снизу: ↗ В карман
- Слева: + История

Палец уже в центре — двигаешь к нужной иконке и отпускаешь.
Отпустил вне — меню закрывается ничего не происходит.

============================================================
АУДИОПЛЕЕР
============================================================

Когда играет — маленькая плашка внизу, над тремя точками.
Тап = развернуть на весь экран (или большой нижний лист).
В развёрнутом: обложка, шкала с точками, плэйлист.
Кнопка "Открыть" = перейти к концепции.

============================================================
ПРОФИЛЬ / ПОВЕСТКА
============================================================

Полноэкранные или крупные нижние листы.
Свайп вниз = закрыть.

============================================================
ОНБОРДИНГ
============================================================

3 полноэкранных слайда.
Свайп влево/вправо = листать.
Точки внизу.
Кнопка "Далее" / "Войти" внизу — под пальцем.

============================================================
АНАТОМИЯ ЖЕСТОВ
============================================================

- Тап на концепции = карточка (peek)
- Тап вне = закрыть всё
- Долгий тап на концепции = радиальное меню
- Свайп вверх/вниз на карточке = развернуть/закрыть
- Свайп влево/вправо на карточке = переключить таб
- Свайп вниз на модалке = закрыть
- Один палец по сцене = вращение
- Два пальца = зум
- Два пальца двигать = пан

============================================================
ПРИНЦИПЫ
============================================================

- Большой палец не тянется вверх. Всё важное — в нижней трети.
- 4 элемента на экране в покое. Всё остальное — по жесту.
- Никаких постоянных меню. Только то что нужно сейчас.
- 3D сцена = фон для всего, но главный герой.
- Всё что появляется — появляется снизу (рука уже там).
- Никаких ховеров (на телефоне их нет).
- Свайпы вместо кнопок "назад".
